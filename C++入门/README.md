# C++ 学习笔记

个人 C++ 学习项目，从零开始系统学习 C++ 编程语言。

## 📂 目录结构

| 章节 | 内容 |
|------|------|
| [01-HelloWorld](./01-HelloWorld/) | C++ 环境搭建、Hello World、注释、变量、常量、关键字与标识符 |
| [02-数据类型](./02-数据类型/) | 整型、sizeof、浮点型、字符型、转义字符、字符串、布尔类型、数据输入 |
| [03-运算符](./03-运算符/) | 算术、赋值、比较、逻辑运算符 |
| [04-程序流程结构](./04-程序流程结构/) | if/switch 选择结构、while/do-while/for 循环、跳转语句 |
| [05-数组](./05-数组/) | 一维/二维数组、冒泡排序 |
| [06-函数](./06-函数/) | 函数定义、调用、值传递、常见样式、声明、分文件编写 |
| [07-指针](./07指针/) | 指针定义、内存空间、空/野指针、const 修饰、指针与数组、指针与函数 |
| [08-结构体](./08%20结构体/) | 结构体定义、数组、指针、嵌套、函数参数、const、综合案例 |
| [09-通讯录管理系统](./09通讯录管理系统/) | 综合实战项目：通讯录管理系统 |
